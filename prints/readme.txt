================================================================================
   RETROPAD - prints de todas as telas (documentação visual)
================================================================================

Este documento descreve visualmente todas as telas do RetroPad para
fins de documentação e apresentação. Execute o servidor e o app para
capturas de tela reais.

--------------------------------------------------------------------------------
TABELA DE CONTEÚDO
--------------------------------------------------------------------------------
1. Tela de Entrada (Join Screen)
2. Modo Gamepad - Layout NES
3. Modo Gamepad - Layout SNES/Genesis
4. Modo Gamepad - Layout PS1
5. Modo Gamepad - Layout N64
6. Modo Gamepad - Layout PS2/Genérico
7. Seletor de Modo (Topo)
8. Overlay de Mouse
9. Overlay de Teclado
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
1. TELA DE ENTRADA (Join Screen)
--------------------------------------------------------------------------------
+-----------------------------------------------------------+
| RETROPAD                                                    |
| ----------------------------------------------------------  |
| [ CAMPO PIN ]                                              |
| ----------------------------------------------------------  |
| [ BOTÃO Jogador 1 ]   [ BOTÃO Jogador 2 ]                 |
| ----------------------------------------------------------  |
| [ GERENCIAR ROMs ]                                         |
| ----------------------------------------------------------  |
| [ ☀ / ☾ Tema ]    [ ⬇ Instalar app ]                      |
| ----------------------------------------------------------  |
| Seletor de Modo: [ Gamepad ] [ Mouse ] [ Teclado ]        |
| ----------------------------------------------------------  |
| Seletor de Sistema (apenas Gamepad):                      |
| [ NES ] [ SNES/Genesis ] [ PS1 ] [ N64 ] [ PS2/Genérico]  |
+-----------------------------------------------------------+

NOTAS:
- Digite o PIN (se houver) e toque em "Jogador 1" ou "Jogador 2"
- O seletor de modo muda a interface inteira
- O seletor de sistema só aparece no modo Gamepad e no PS2
- Gire o celular para modo paisagem (auto-detectado)

7. SELETOR DE MODO (Topo - Visível em Todas as Telas)
--------------------------------------------------------------------------------
+-----------------------------------------------------------+
| RETROPAD | [ Gamepad ] [ Mouse ] [ Teclado ]  [ PIN field]    |
+-----------------------------------------------------------+

COMO FUNCIONA:
- Toque no seletor para mudar de modo instantaneamente
- A interface inteira se reorganiza (gamepad/mouse/teclado)
- A escolha é salva na sessão do usuário
- No modo Gamepad: aparece também o seletor de sistema
